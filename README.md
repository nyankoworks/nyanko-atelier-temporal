# にゃんこの時空アトリエ 🐾

note風のポートフォリオサイトです。
**`works/` の中に作品フォルダを1つ置くだけ** で、トップページに自動でカードが増えます。

---

## いちばん大事なこと（これだけ覚えればOK）

1. `works/` の中に、作品ごとにフォルダを1つ作る
2. その中に「中身」を入れる（下のルール参照）
3. 保存して GitHub Desktop の「同期（Push）」を押す
   → 数分でサイトが自動で更新されます

**いちばんラクな更新方法：`更新.bat` をダブルクリック**（Windows）。
works/ と _AIノート/ を読み直してサイトを作り直し、ページを自動で開きます。
（Macの人は `更新_mac.command` をダブルクリック）

手動でやる場合は `python3 build.py` を実行すると `_site/index.html` ができます。

### AIノートの更新も同じ
`_AIノート/` に `2026-08-29_タイトル.md` を足す → **`更新.bat` をダブルクリック** → 反映されます。
（ファイルの書き方は「公開・非公開の分け方」の下や _AIノート/_つかいかた.txt を参照）

## 作品フォルダの中身のルール（お約束）

フォルダの中に入れたものによって、カードの見た目が自動で決まります。

| 入れるもの | どうなる |
|---|---|
| `link.txt`（1行目にURL） | note・YouTube などの外部リンクのカード |
| `index.html` | 自作のWebページ作品としてリンク |
| 画像（png/jpg など、複数OK） | サムネイル＋クリックで拡大表示 |
| PDF | PDFを開くカード |

- **フォルダ名がそのままタイトル**になります。
- 先頭に `09_` のように数字を付けると **並び順の目印**（数字が大きいほど新しい＝上に表示）。

### 任意で足せるファイル

| ファイル | はたらき |
|---|---|
| `title.txt` | タイトルを上書き（1行） |
| `about.txt` | カードの説明文 |
| `cover.png` / `thumb.png` | サムネイルを指定したいとき |
| `date.txt` | 日付（例 `2026-08-29`）。並び替えにも使える |

- フォルダ名・ファイル名が `_` や `.` で始まるものは **下書き扱いで表示されません**。

## 計測ツールの入れ方（GA4・ヒートマップ・クリック数）

`config.json` にIDを入れるだけで、**全ページに自動でタグが入ります**（空なら入りません）。

```json
"ga4_id": "G-XXXXXXX",       ← GA4の測定ID（アクセス解析）
"clarity_id": "xxxxxxxxxx"   ← Microsoft ClarityのID（ヒートマップ）
```

### GA4の測定IDのとり方
GA4管理画面 →「管理」→「データストリーム」→ 対象ストリームを開くと `G-` から始まる**測定ID**があります。それを `ga4_id` に貼るだけ。

### Microsoft Clarity のIDのとり方
clarity.microsoft.com にログイン → プロジェクトを作成 → Settings（設定）の **Clarity project id**（10桁前後の英数字）を `clarity_id` に貼るだけ。ヒートマップとセッション録画が使えます。

### クリック数（どのカードが押されたか）
トップページのカードをクリックすると、**GA4に「select_card」というイベント**が自動で送られます（どの作品が押されたかは `card_title` で分かります）。GA4の「レポート → エンゲージメント → イベント」で確認できます。Clarityを入れていれば、クリックの多い場所がヒートマップでも見えます。

> 入れたら `更新.bat` をダブルクリックすれば反映されます。

## サイトの見た目・名前を変えたいとき

`config.json` を編集します。

| 項目 | 意味 |
|---|---|
| `site_title` | サイトの名前 |
| `site_subtitle` | 小さく出るサブ名（英字） |
| `intro` | トップの紹介文 |
| `accent` | アクセント色（例 `#e9a0a0`） |
| `newest_first` | 新しい作品を上に出すか（true/false） |

## 公開・非公開の分け方 🔒

**フォルダ名・ファイル名の先頭に `_`（アンダーバー）を付けると「完全非公開」**になります。

- サイトに表示されません
- GitHub（ネット）にも上がりません（`.gitignore` で除外）
- 自分のPCの中だけに残ります

こども漫画のネタ・下書き・素材など、まだ見せたくないものは `_` 付きフォルダへ。
例：`works/_こども漫画ネタ帳/`、`_素材おきば/`

公開したくなったら、**先頭の `_` を外して build するだけ**で一覧カードになります。

> メモ：無料プランでネット公開する場合、GitHubの「置き場所（リポジトリ）」自体は公開になります。
> だから“本当に見せたくないもの”は上のルールで「ネットに上げない」のが確実です。
> もし「パスワードを知っている人だけに見せたい（限定公開）」をやりたい場合は、
> 別途パスワードゲートを付けられます（簡易的な鍵）。相談してください。

## フォルダ構成

```
nyanko-atelier-temporal/
├─ works/          ← ここに作品フォルダを足していく
├─ assets/         ← デザイン（style.css）
├─ config.json     ← 名前・GA4・色などの設定
├─ build.py        ← サイトを作るツール
├─ _site/          ← build.py が作る「公開用の中身」（自動生成）
└─ .github/        ← 自動公開のしくみ
```
